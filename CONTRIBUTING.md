# Contributing

Thank you for your interest in contributing to AGDO-MT.

## Development Setup

Clone the repository

```bash
git clone https://github.com/alyasirharahap/AGDO-MT-Inversion.git
cd AGDO-MT-Inversion
```

Install the package

```bash
pip install -e .
```

Install testing dependencies

```bash
pip install pytest
```

Run all tests

```bash
pytest
```

## Coding Style

- Follow PEP 8
- Use NumPy-style docstrings
- Include type hints where appropriate
- Add unit tests for new functionality

## Pull Requests

Please ensure that:

- All tests pass.
- New features include documentation.
- Public APIs remain backward compatible whenever possible.
